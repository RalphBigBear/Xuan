## 🛠️ 技术实现

### SBCP L∞ 编码原理

```
SBCP = State-Based Compression Protocol
L∞  = L-infinity Norm (最大压缩，保留核心峰值)

编码结构:
{
  "id": "PHYSICS_001",
  "hash": "67dfe09c",           // 语义哈希（快速检索）
  "core": {                      // L∞ 核心（最高频特征）
    "t": "波粒二象性",           // term 压缩
    "f": "经典物理",             // from 压缩
    "d": "状态模式",             // domain 压缩
    "s": -0.7                   // entropy_score 压缩
  },
  "western": {                   // 西方逻辑编码
    "logic": "互补性|多模态性",
    "key": "粒子/波统一"
  },
  "eastern": {                   // 东方直觉编码
    "insight": "阴阳|无常",
    "key": "一多不二"
  },
  "triggers": [                  // 触发词（快速匹配）
    "光", "既是", "也是", "状态"
  ]
}
```

### 关键特性

1. **语义哈希** (MD5 截断)
   - 快速精确匹配
   - 碰撞率极低
   - 支持分布式索引

2. **L∞ 核心压缩**
   - Term 截断至 20 字
   - 域名截断至 15 字
   - 保留熵减评分

3. **东西方分离编码**
   - 西方：逻辑特征（关键词管道符连接）
   - 东方：洞察特征（关键词管道符连接）
   - 支持独立查询和联合查询

4. **触发词倒排索引**
   - 198 个唯一触发词
   - 平均每个概念 6.8 个触发词
   - 0-1ms 查询响应
